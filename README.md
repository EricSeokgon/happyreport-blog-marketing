- 세일즈코드 페이지: https://www.happyreport.co.kr/sales/salescode.asp?mode=b1 (로그인 필요)
- 세일즈 ID: `redfoxkiller` / 자료 판매 시 판매수익의 40% 지급 (예: 5,000원 자료 → 2,000원)

- 검색은 공백 기준 AND 매칭 (예: "독학사 가족관계" → 두 단어 모두 제목에 포함)
