# 글 작성·발행 체크리스트 + 채널별 템플릿

1·2차 세션에서 발행한 14건의 공통 규칙을 정리한 것입니다. 새 글은 이 순서대로 만들면 기존 글과 톤·구조가 맞습니다.

## 1. 작성 전

- [ ] 공개 페이지·피드와 저장소 이력을 대조해 중복 발행을 피하고 마지막 수정시각을 확인
- [ ] 공식 일정·시험 단계·전공·채용 연도·지원 대상이 현재 글과 맞는지 확인하고 출처·확인일 기록
- [ ] 검색결과 존재, 개별 자료 적합성, 실제 수익 귀속을 구분해 기록

- [ ] 키워드 세일즈 링크가 검색결과 1건 이상으로 연결되는지 확인 (`tools/make_sales_links.py`로 생성 → 브라우저로 확인)
- [ ] 채널 배분: 자격증·독학사·시험족보·방통대(워드프레스 쪽) → 에릭 자료노트 / 리포트·자소서·실습일지·방통대(게시판 쪽) → hadesyi / 취업·면접·기출복기 → eric
- [ ] 제목에 연도("2026") 또는 시즌("2026 하반기", "2학기") 포함, 핵심 키워드는 제목 앞쪽에
- [ ] 글당 고유 정보 3가지 이상 확보 (일정·전형·과목 특성·문항 수·페이지 수 등). 템플릿만 바꾼 복제 글 금지

## 2. 본문 구조 (공통)

1. 도입 1문단: 수험생·지원자의 어려움 + 이 글이 해결하는 것
2. 소제목 2~3개: "시험/면접 특징", "공부/준비 포인트", "자료 소개" (자료는 문항 수·해설 유무·분량을 구체적으로)
3. 세일즈 링크: `<strong>키워드 자료 모아보기:</strong>` 다음 줄에 `<a href="링크" target="_blank" rel="noopener">앵커 텍스트</a>`
4. 마무리 소제목(선택): 준비 순서·일정 알림
5. 제휴 고지(필수, 마지막 줄): `※ 본 글에는 제휴 링크가 포함되어 있으며, 자료 구매 시 작성자에게 일정 수익이 발생할 수 있습니다.`

## 6. 금지·주의

- 로그인·자격증명 입력 대행 금지, 계정 정보·토큰을 저장소에 기록 금지
- 제휴 고지 삭제 금지 (표시광고법 대응)
- 자료의 문항 수·분량 등은 해피레포트 상품 설명에 있는 수치만 사용 (없는 수치를 만들지 않음)
- **과제물(방통대 등) 글에는 "참고자료는 구조·자료 조사 용도로만, 그대로 제출 시 표절·부정행위" 문구를 반드시 포함** (방송대는 상업용 자료·생성형 AI 부정 사용을 명시적으로 단속함). 자료를 "그대로 내면 된다"는 식의 표현 금지
- 초안(`drafts/`)의 `<!-- [검증] -->`·`[자료 설명]`·`[허브 글 URL]` 플레이스홀더가 남아 있는 상태로 발행 금지

## 7. 2026-10-13 점검 기록

키워드 19개는 [공개 결과 확인](LINK_AUDIT_2026-10-13.md) 완료. 관리자 인증·판매실적·검색엔진 등록 상태는 미확인입니다. 복구한 본문과 새 수정안을 구분하고, 공개 `content.rendered`를 편집기 raw 원본으로 간주하지 않습니다. 신규 제휴 링크에는 `rel="sponsored noopener"`를 사용하고 기존 고지를 유지합니다.
