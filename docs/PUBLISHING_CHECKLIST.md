# 글 작성·발행 체크리스트 + 채널별 템플릿

1·2차 세션에서 발행한 14건의 공통 규칙을 정리한 것입니다. 새 글은 이 순서대로 만들면 기존 글과 톤·구조가 맞습니다.

## 1. 작성 전

- [ ] 키워드 세일즈 링크가 검색결과 1건 이상으로 연결되는지 확인 (`tools/make_sales_links.py`로 생성 → 브라우저로 확인)
- [ ] 채널 배분: 자격증·독학사·시험족보 → hadeslee / 리포트·자소서·실습일지·방통대 → hadesyi / 취업·면접·기출복기 → eric
- [ ] 제목에 연도("2026") 또는 시즌("2026 하반기", "2학기") 포함, 핵심 키워드는 제목 앞쪽에
- [ ] 글당 고유 정보 3가지 이상 확보 (일정·전형·과목 특성·문항 수·페이지 수 등). 템플릿만 바꾼 복제 글 금지

## 2. 본문 구조 (공통)

1. 도입 1문단: 수험생·지원자의 어려움 + 이 글이 해결하는 것
2. 소제목 2~3개: "시험/면접 특징", "공부/준비 포인트", "자료 소개" (자료는 문항 수·해설 유무·분량을 구체적으로)
3. 세일즈 링크: `<strong>키워드 자료 모아보기:</strong>` 다음 줄에 `<a href="링크" target="_blank" rel="noopener">앵커 텍스트</a>`
4. 마무리 소제목(선택): 준비 순서·일정 알림
5. 제휴 고지(필수, 마지막 줄): `※ 본 글에는 제휴 링크가 포함되어 있으며, 자료 구매 시 작성자에게 일정 수익이 발생할 수 있습니다.`

## 3. 채널별 HTML 규칙

| 채널 | 붙여넣기 위치 | HTML 규칙 | 고지 스타일 |
|---|---|---|---|
| 오후의레포트 (hadeslee, 워드프레스) | wp-admin → 새 글 → 코드 편집기 | 여러 줄 HTML, 소제목 `<h2>`/`<h3>`, 태그는 `<strong>` | `<p style="font-size:0.9em;color:#666;">` |
| 하데스레포트 (hadesyi, 그누보드) | 리포트 게시판(bo_table=free) 글쓰기 → 에디터 HTML 탭. 방통대 글은 방송통신 게시판 | 소제목 `<h3>`, 말머리 `[시험자료]`·`[면접자료]` 등, `<br />` 사용 | `<p style="font-size:0.9em;color:#666;">` |
| eric (erichlee.blogspot.com, 블로거) | blogger.com → eric → 새 글 → HTML 보기 | **한 줄 HTML** 권장(줄바꿈이 `<br>`로 바뀜), 소제목 `<h3>`, 강조 `<b>`, 라벨 4~5개 | `<p style="font-size:small; color:#777;">` |

템플릿(블로거용 한 줄 예시):

```html
<p>도입 문단</p><h3>준비 포인트</h3><ul><li><b>포인트 1</b> - 설명</li><li><b>포인트 2</b> - 설명</li></ul><h3>추천 자료</h3><p>자료 소개</p><ul><li>자료 1 (문항 수·분량)</li></ul><p><b>키워드 자료 모아보기:</b><br /><a href="세일즈링크" target="_blank" rel="noopener">앵커 텍스트</a></p><p style="font-size:small; color:#777;">※ 본 글에는 제휴 링크가 포함되어 있으며, 자료 구매 시 작성자에게 일정 수익이 발생할 수 있습니다.</p>
```
