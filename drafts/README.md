## 표기 규칙

- `<!-- [검증] -->` : 발행 전 브라우저로 확인할 링크·사실. 확인 후 주석은 지우고 발행
- `[자료 설명]` : 세일즈 검색결과 상위 자료의 실제 구성(예: "A+ 작성 예시 6페이지")으로 교체. 없는 수치는 만들지 않음
- `[허브 글 URL]` : 먼저 발행된 글의 라이브 URL로 교체(내부 링크)
- 본문은 `<!-- 본문 시작 -->` ~ `<!-- 본문 끝 -->` 사이만 복사. 블로거(eric)용은 한 줄 HTML
